# Roadmap — «Возрождение»

> Темп: ~20 ч/неделю. Оценки ориентировочные: на первом проекте с новым стеком закладывай
> запас ×1.5. Каждый этап заканчивается **деплоем на прод** — продукт растёт работающими кусками.

## Обзор

| # | Этап | Недели | Результат | Главное, чему учишься |
|---|---|---|---|---|
| 0 | Фундамент и walking skeleton | 1–2 | Пустое приложение фронт → API → БД задеплоено на VPS, CI зелёный | Rails API, основы React, Vite, GitHub Actions, Kamal |
| 1 | Аутентификация и роли | 3–4 | Вход по email + пароль, роли, защищённые страницы | Cookie-сессии в SPA, CSRF, Pundit, React Router, формы |
| 2 | Мастер и услуги | 5 | Мастер управляет своими услугами, гость видит прайс | CRUD-цикл React ↔ API, TanStack Query (мутации, инвалидация) |
| 3 | Расписание мастера | 6 | Мастер добавляет рабочие интервалы на день | Exclusion constraints в PostgreSQL, работа со временем и часовыми поясами |
| 4 | Слоты и запись | 7–8 | Гость или клиент записывается, мастер подтверждает или создаёт запись сам | Сервисные объекты, алгоритм слотов, конкурентность, state machine |
| 5 | Клиенты и личный кабинет | 9–10 | Мастер ведёт базу, шлёт приглашения; у клиента есть ЛК | Токены `generates_token_for`, Active Record Encryption, согласия на ПДн |
| 6 | Уведомления и Telegram-бот | 11–12 | Напоминания в Telegram и по email, автоотмена `pending` | Solid Queue, паттерн «стратегия» для каналов, webhooks, Bot API |
| 7 | Дизайн, лендинг, отзывы | 13–14 | Красивый публичный сайт, отзывы с модерацией | Дизайн-система на Tailwind/shadcn, SEO для SPA |
| 8 | Статистика и запуск | 15–16 | Сбор событий, бэкапы, мониторинг, политика ПДн — друг работает в системе | Эксплуатация: бэкапы, мониторинг ошибок, онбординг пользователя |

**MVP — конец этапа 6** (около 3 месяцев): друг уже может принимать записи через систему.
Этапы 7–8 делают продукт «публичным» и готовым к портфолио.

## Этапы подробнее

### Этап 0. Фундамент и walking skeleton (недели 1–2)
Задачи — в `docs/sprints/sprint-01.md`.

### Этап 1. Аутентификация и роли (недели 3–4)
- ADR: cookie-сессии против JWT для SPA
- `User` с ролями; генератор аутентификации Rails 8, адаптированный под API
- CSRF-защита для SPA, настройки cookie (HttpOnly, Secure, SameSite)
- Pundit: базовые политики
- React: страницы входа и выхода, контекст текущего пользователя, защищённые маршруты
- Сид-данные: админ-мастер

### Этап 2. Мастер и услуги (неделя 5)
- `Master`, `Service`, `MasterService` (цена, длительность), настройки мастера (буфер, шаг сетки)
- Кабинет мастера: CRUD услуг
- Публичная страница прайса

### Этап 3. Расписание мастера (неделя 6)
- `WorkInterval` + exclusion constraint (интервалы мастера не пересекаются)
- UI: календарь на неделю/день, добавление и удаление интервалов
- Часовой пояс Europe/Moscow, хранение в UTC — тесты на границы суток

### Этап 4. Слоты и запись (недели 7–8)
- Сервис расчёта свободных слотов (`Slots::Available`): интервалы − записи, услуга + буфер, сетка 15 минут, правило «за 2 часа»
- `Appointment` + exclusion constraint; статусы и переходы
- `Appointments::Book` — запись клиентом (`pending`)
- Кабинет мастера: лента записей, подтверждение и отмена, ручное создание записи (в том числе в прошлом)
- Публичный flow записи: услуга → дата → слот → контакты → готово

### Этап 5. Клиенты и личный кабинет (недели 9–10)
- `Client` без `User`; CRUD клиентов у мастера; заметки и противопоказания (шифрование)
- Приглашения: ссылка → установка пароля → ЛК
- `Consent`: согласие на обработку ПДн при регистрации и записи
- ЛК клиента: мои записи, отмена, история

### Этап 6. Уведомления и Telegram-бот (недели 11–12)
- Абстракция каналов уведомлений; `Notification`
- Email (SMTP-провайдер в РФ)
- Telegram-бот: привязка аккаунта по deep link (`/start <token>`), уведомления мастеру о новой записи, напоминания клиенту
- Фоновые задачи: напоминания, автоотмена неподтверждённых записей
- **🚀 MVP: друг начинает пользоваться**

### Этап 7. Дизайн, лендинг, отзывы (недели 13–14)
- Мудборд и айдентика → токены → макеты (вместе с Claude)
- ADR: SEO для SPA (пререндер лендинга или отдельная статическая страница)
- Лендинг: о мастере, услуги, отзывы, контакты, карта
- Отзывы: оставить после завершённого визита, модерация мастером

### Этап 8. Статистика и запуск (недели 15–16)
- Сбор событий (записи, отмены, неявки, источники)
- Бэкапы БД в S3-хранилище в РФ + проверка восстановления
- Мониторинг ошибок, uptime-мониторинг
- Политика конфиденциальности, оферта/правила записи
- README и описание проекта для портфолио
